garret - identity masters
=========================

The name is always written lowercase: garret. Never "Garret", never all caps.

The wordmark is the word in a connected script followed by ONE vermilion dot,
read as a full stop. That dot is the only colour. Everything else is
monochrome: ink on paper in light surroundings, paper on ink in dark ones, the
dark version an exact inversion. No second colour, gradient, texture, shadow
or outline. The dot is the same vermilion on both backgrounds. The wordmark is
not the interface font; the application's text stays in its own sans.

The app icon is the script "g" and the same dot on a rounded square:
appicon-light is a paper square with an ink g, appicon-dark an ink square with
a paper g. Use whichever contrasts with the surface it sits on.

Files (true-alpha RGBA PNG, 1024 px wide):

  garret-wordmark-ink.png     wordmark for light backgrounds
  garret-wordmark-paper.png   wordmark for dark backgrounds
  garret-icon-ink.png         the "g." mark alone, for light backgrounds
  garret-icon-paper.png       the "g." mark alone, for dark backgrounds
  garret-appicon-light.png    app icon, paper square
  garret-appicon-dark.png     app icon, ink square

These are PRE-VECTOR RASTER MASTERS, keyed from a generated concept. A clean
vector (SVG) redraw is planned: an exact inversion, the vermilion fixed as
one value, and the icon checked at 16, 32 and 64 px.

The artwork is original to this project; no third-party licence applies.

scripts/render-icons derives every application, window, package and page icon
from these files. Change a master, then rerun it; do not edit its outputs.
